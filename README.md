# The Webbery
## About
The webbery is a small portolio website hosted at https://the-webbery.streamlit.app
It is maintained by C98 through hackclub. It is to host my projects I work on through hackclub, and build a portfolio of project I make while I'm here. :)

## Code
It was built in and hour and a bit in Python using the streamlit library. It is hosted on https://the-webbery.streamlit.app but you can build it yourself! Simply download the main.py file, and the .csv (or fork this repo), then run `pip install streamlit` (or `uv add streamlit` if using uv) and run `streamlit run main.py` and that's it!
